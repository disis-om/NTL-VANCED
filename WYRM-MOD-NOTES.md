## 2. How NTL works (relevant bits)

- `manifest.json` (MV3). `key` and `update_url` were **removed** so the unpacked copy gets its own id and is never auto-updated/overwritten. Name `NTL VANCED`. **Keep `version` = 9.67** (NTL sends it to ntl-slither.com as `ver=`/`modv=` for tags/team features); the mod version lives in **`version_name`** (shown on the Chrome card) — `tinyscr.js` copies it to `localStorage.wyrmversion`, which `WYRM_VER` in main-mt.js reads (footer credit). Bump `version_name` when adding features.
- `game.json` (declarativeNetRequest) blocks slither.io's own game script; `tinyscr.js` (content script) then injects `jquery`, `fstags.js`, `emoji-data.js` and **`main-mt.js`** into the page.
- **`main-mt.js` = the entire game client + mod, 7.4 MB, minified.** Everything custom lives at the **top** of this file.
- Extension id is read at runtime from `localStorage.tinyscrID` (set by tinyscr.js) — nothing is hard-coded, so the new id is fine.

### 3.1 `NTL_EB` — Eyes Back
Toggle key: keymap id **`eyesback`** (default `U`, remappable in Revamp Keys; `""` = disabled). HUD `#eb-hud` top-centre shows state + key.

What it does: while ON, the angle byte the game already sends is replaced by "behind the head ± eps", alternating sides (the manual left-right flick, automated). Same 1-byte packet, no new packets. Steering: sigma-delta duty cycle toward the mouse angle. Heading is predicted server-side-faithfully (dead-reckoning with `rtt/2` from `mr`, anchored on every server heading update via a hooked `snake.ang` setter). `cfg` at top of module: `eps` (steps of 360/251 from exact 180°), `turnMargin`, `band`, `turnRate`, `epsMax`, `snap`.

Patch point (single line, unique): in the mouse→angle send code
```
Ld=251*Jd/He|0,NTL_EB.on&&(Ld=NTL_EB.tick(1<Yd?Jd:null,snake,ab),snake.J=Ld*He/251),(Wf||Ld!=_c)&&(…ws.send(ib.buffer))
```
`Jf` also got `{id:"eyesback",key:"u",label:"Eyes Back (toggle)"}` appended (after `enableselect`).

Known behaviour: ±1 tick wobble (~8° on tiny snakes, less on big ones) is inherent to the server's turn rate.

### 3.1b `NTL_EC` — Center Eyes
Client-side only. Keymap id `eyecenter` (default `I`, toggle/hold). Hook in the render loop: `ib=Math.cos(cb.J)*cb.TA;db=Math.sin(cb.J)*cb.TA;NTL_EC.on&&cb===snake&&(ib=db=0);` — NTL then eases the own snake's pupil offsets `cb.mA/cb.CA` to 0. Nothing is sent to the server. Row in the EE menu; `NTL_KM` skips `eyesback`/`eyecenter` (they handle their own key).

### 3.2 `NTL_KM` — Key Modes
Lets the user change how a key behaves: hold→toggle, double-tap→single-tap, double-tap→hold, Eyes Back toggle→hold. Stored in `localStorage.my_keymodes` `{actionId: mode}`.

Implementation: window `keydown`/`keyup` listeners in **capture phase, registered before NTL's** (NTL uses bubble-phase window listeners), which swallow the physical event and dispatch synthetic `KeyboardEvent`s (flagged `ev.__rk=1`) that NTL then handles normally. Double-tap is synthesised as `[f4, key, key]` (f4 only resets NTL's double-tap memory). Actions that are cyclers/one-shots (`FIXED` set) cannot change mode.

### 3.3 `NTL_RK` — Revamp Keys popup

## 5. Workflow for changes

1. Write a Node patch script (`tools/patches/patch_NN.js` style): read main-mt.js, `rep(anchor, replacement)` that throws unless the anchor occurs exactly once, write back. Never hand-edit the 7 MB file in an editor that reflows it. **Gotchas:** main-mt.js contains real `—`/`·`/`'` characters, not `\u2014` escapes — anchors must use the real characters; put scripts in files (shell quoting of `node -e` eats backslashes in regexes); grep needs `-a` (file has a NUL byte).
2. `node --check main-mt.js` — must print nothing.
2b. Changelog entry + `version_name` bump + (ship builds) `NTL_WN.NOTES`.
2c. Build the zip ONLY with `tools\mkzip.ps1` (self-verifies: 0 backslash entries, `s/prev3.webp` present). PowerShell `Compress-Archive` zips (≤ v3.5) broke the Android loader.
3. For UI work, build a harness page: extract the HTML string (e.g. evaluate `E3()` / the `Zr()` prepend string with stubbed function names via a `Proxy` scope), include `bootstrap.css` + `jquery-2.2.4.min.js`, paste the modules, serve over `http://` (file:// can't be automated) and screenshot.
4. Reload the extension in `chrome://extensions`, test on slither.io.

**Ground rules from the owner (Om):**
- **Never autofocus a field.** Focusing pops the Android keyboard open as soon as a panel appears; let the user tap the field.
- **On-screen controls use pointer events, never `click`.** Only the primary touch point produces a compatibility click, so a `click` handler is dead whenever another finger is already steering.
- Never modify NTL's own DOM structure, handlers or the network protocol — layer on top (CSS overrides, observers, wrapper modules). "Kuch bigadna mat."
- Every new UI must match the theme above ("premium", same as the Revamp Keys popup) and include a reset-to-defaults where it makes sense.
- Keys that are permanent in NTL (boost Space/Shift/↑, turn ←/→, Y, 5/6 after Q, F3/F4, F8, Esc) are left alone.
