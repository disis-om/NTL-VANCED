# NTL VANCED vs NTL MOD

NTL VANCED is built on top of NTL MOD 9.67. Everything NTL does still works — the bot, smart bot, team system, tags, custom skins, key remapping, settings, minimap and the team roster are all untouched underneath. VANCED adds a modern interface, mobile-grade controls, a real chat, live arena tools and an updater, without changing the game protocol or NTL's own services.

## What NTL VANCED adds

### Interface
| | NTL MOD | NTL VANCED |
|---|---|---|
| Home screen | Bootstrap buttons in a grey card | Launcher tiles with icons and sub-labels, a real PLAY button, instant load |
| Settings | One long page | Same page restyled with a category sidebar, styled sliders, toggles and colour picker |
| Mod settings | Spread across the NTL page | **Vanced settings** popup: General, Controls, Spine, Pro Guard, Bot & AI, Global chat, Updates & About, Changelog |
| HUD | Six loose stat boxes | One compact stats block, themed ping/FPS graph, themed clock and credit line |
| Panels | Fixed look | Panel transparency **and** content transparency sliders, UI size stepper that scales every popup, movable/resizable log and chat with NTL's own edit mode |
| Mobile | Desktop layout | Responsive layouts for every panel and popup, hover effects removed on touch |
| Look & feel | — | Consistent dark theme, gradients, skeleton-free instant rendering |

### Controls
| | NTL MOD | NTL VANCED |
|---|---|---|
| Key remapping | Basic remap in settings | **Revamp Keys** menu: every action, search, reset, and per-key **hold / toggle / tap** modes |
| Touch | Built-in mobile buttons | **On-screen controls editor**: any action, boost, joystick and zoom bar placed anywhere, per-widget size/opacity, multi-touch safe |
| Steering | Mouse / joystick | **Arrow control** — virtual-cursor steering with a live preview, plus a dedicated touch layer so panels never steal a steering finger |
| Cursor | System cursor | **Aim cursor** with a skin gallery (eleven neon arrows, custom image) |
| Eyes | — | **Eyes Back** (the pro eye-flick on a key) and **Center Eyes** |

### Gameplay tools
| | NTL MOD | NTL VANCED |
|---|---|---|
| Body view | — | **Spine mode**: body hidden, spine drawn from the collision point, fully configurable with live preview |
| Performance | Graphics level | **Performance mode** (`=`) — render scale + lighter effects, with a diagnostics meter |
| Bot | Bot + smart bot | Same NTL bot, plus its target and weighed paths drawn in the arena and a **Thinking log** |
| Diagnostics | — | Built-in diagnostics report (gate counters, assets, device, errors, performance) |

### Chat
| | NTL MOD | NTL VANCED |
|---|---|---|
| Team chat | Plain text box | Message bubbles with time, themed emoji picker |
| Media | — | **One picker** for Emoji · GIF · Stickers · Memes (KLIPY) — categories, Recent, autocomplete; media renders inline for VANCED players |
| Global chat | — | **TEAM | GLOBAL** tabs in one box: a global room across servers, unread badge, users, nickname |

### Servers & arenas
| | NTL MOD | NTL VANCED |
|---|---|---|
| Server list | Ping table | **Server picker** popup: search by id, IP, country code or country name, favourites, saved custom arenas (IPv4/IPv6) |
| Team map | Minimap in game only | **Team map on the home screen**: live arena picture with your team's icons, players and top ten, JOIN in one tap |
| Live view | — | **Live Battledomes** (experimental): rendered live arena preview with zone, food, snakes, stats and top ten, powered by Wyrm |
| Leaderboards | NTL realtime page | Wyrm live monitoring |

### Updates
| | NTL MOD | NTL VANCED |
|---|---|---|
| Updating | Reinstall the extension | **Over-the-air**: install once, updates arrive in-game with release notes; stable and beta channels, STABLE fallback, automatic rollback if a build fails to start |
| Notices | Update nags in chat | Removed; a **What's new** popup per version instead |

## Why prefer NTL VANCED

1. **Nothing is lost.** Every NTL feature, service and setting is still there; VANCED layers on top and never touches the game protocol.
2. **It fits a phone.** Real touch controls, arrow steering, responsive panels and a UI size control — NTL was built for a mouse.
3. **It stays current by itself.** One install, then updates come to you; a beta channel if you want features early.
4. **It talks.** Emoji, GIFs, stickers, memes and a global room, instead of a plain text box.
5. **It sees the arenas.** Team map, live Battledome preview and a searchable server picker before you press PLAY.
6. **It looks like one product.** A single consistent theme across every menu, popup and panel.
