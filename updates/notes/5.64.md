# Backups, lobby control, cleaner updates

## Backups
- One **.ntlvanced** file holds everything: NTL and Vanced settings, keys, on-screen layouts, theme, custom arenas and skins
- **BACKUP** and **RESTORE** in Vanced › Updates & About; older `.ntlmod` files still restore

## Lobby
- Can be switched off in **Vanced › General**
- Appears only after a real round — coming back from the skin editor or settings goes straight to the home screen

## Updates
- **UPDATE** appears only when a new version is waiting
- Checks no longer hang: every request times out and the first mirror that answers wins
- **STABLE** and **PACKAGED** are explained in the card and shown only when they apply

## Fixes
- Custom tag authorisation no longer throws when a saved tag is gone
- Loading screen removed; the start-up work that made the launcher appear sooner stays
