# Lobby, faster start, NTL 9.68 support

## Lobby
- Every round now ends in the lobby: final length, personal best, and one tap back into the game
- Home is one tap away

## Faster start
- Files are preloaded as the page opens; the launcher appears sooner, especially on phones
- A themed loading screen replaces the blank page while the mod starts
- Background checks run less often, keeping the first seconds smooth

## NTL 9.68
- playerID support: fully compatible with NTL 9.68 servers
- Chat commands `!id`, `!idlist`, `!idforce`

## Mobile
- Device mode in Vanced › General: Auto, Desktop or Mobile
- Phones get arrow control and a boost button set up on first start

## Themes and home
- Spidey is the default theme
- Wallpaper blur on by default
- Cleaner home screen: logo, Team map and Live Battledomes removed

## Fixes
- Small fixes and clean-ups
